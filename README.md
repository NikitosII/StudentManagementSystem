## Описание

Проект представляет собой консольное приложение на C++, которое позволяет пользователю управлять информацией о студентах. Программа поддерживает добавление студентов из файла или через консоль, поиск студентов, удаление студентов, а также группировку студентов по размеру стипендии и сортировать по проценту оценок за семестр.

## Функциональность

- **Добавление студента**: Пользователь может добавить студента, указав группу, инициалы, размер стипендии, оценки и дополнительную информацию.
- **Поиск студента**: Пользователь может искать студента по инициалам.
- **Удаление студента**: Пользователь может удалить студента по инициалам.
- **Группировка студентов по стипендии**: Пользователь может группировать студентов по размеру стипендии и сохранить результат в файл.
- **Сортировка по проценту оценок**: Пользователь может сортировать по общему проценту оценкок "неуд/удовл" в группах. Введётся подсчёт данных оценок и выводится процентное отношение в группе.

## Использование

1. Склонируйте репозиторий:
    ```sh
    git clone <URL репозитория>
    ```
2. Перейдите в директорию проекта:
    ```sh
    cd <имя директории проекта>
    ```
3. Скомпилируйте проект:
    ```sh
    g++ -o main StudentManagementSystem.cpp Table.cpp Student.cpp
    ```
4. Запустите программу, указав путь к файлу с данными:
    ```sh
    ./main <путь к файлу>
    ```
    Например:
    ```sh
    ./main data.txt
    ```

### Пример использования

1. Создайте текстовый файл `data.txt` с содержимым:
    ```
    Sidorov.S.D. 3342 44554 2200 Humanitarian
    Petrov.T.V. 3315 33333 1000
    Ivanov.I.I. 3315 44443 1000
    NoName 1111 44455 1999
    ```
2. Скомпилируйте и запустите программу:
    ```sh
    g++ -o main StudentManagementSystem.cpp Table.cpp Student.cpp
    ./main data.txt
    ```
3. Следуйте инструкциям в меню:
    ```
    1. Добавить информацию о студенте
    2. Найти информацию о студенте
    3. Удалить информацию о студенте
    4. Процент неуспевающих по группам
    5. Группировка студентов по стипендии
    0. Выход
    Введите номер пункта: 1
    ```
4. Выберите способ добавления студента:
    ```
    1.1. Из файла
    2.1. Через консоль
    Введите номер пункта: 1
    ```
    Программа считает данные из файла и добавит студентов в хеш-таблицу.

5. Выберите пункт 2 для поиска студента:
    ```
    Введите номер пункта: 2
    Введите инициалы для поиска: Sidorov.S.D.
    ```
    Программа выведет информацию о студенте:
    ```
    3342 Sidorov.S.D. 2200 4-5-5-4-4 Humanitarian
    ```

6. Выберите пункт 3 для удаления студента:
    ```
    Введите номер пункта: 3
    Введите инициалы для удаления: NoName
    ```

7. Выберите пункт 4 для группировки студентов по проценту неуспевающих:
    ```
    Введите номер пункта: 4
    Введите порог процентного соотношения неуспевающих: 10
    ```
    Программа выведет группы, в которых процент оценок "неуд/удовл" превышает указанный порог.
    ```
    Группа 3315: 60%
    ```
8. Выберите пункт 5 для группировки студентов по стипендии:
    ```
    Введите номер пункта: 5
    ```
    Программа выведет студентов, сгруппированных по размеру стипендии, и предложит сохранить результат в файл.
    ```
    Размер стипендии: 1000
    Студенты: Ivanov.I.I., Petrov.T.V.,

    Размер стипендии: 2200
    Студенты: Sidorov.S.D.,

    ВЫ хотите сохранить результат в файл? (да/нет): да
    Данные успешно сохранены в sorted_data.txt
    ```
    
## Структура проекта

- `Student.h`: Определение класса `Student`, представляющего студента.
- `Table.h` и `Table.cpp`: Определение и реализация класса `Hashmap`, который управляет хеш-таблицей студентов.
- `StudentManagementSystem.cpp`: Основной файл программы, содержащий меню для взаимодействия с пользователем.
